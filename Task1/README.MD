#### Кейс-задача № 1
Дан одномерный массив А размерности N. Найти сумму отрицательных элементов, расположенных между максимальным и минимальным.

#### Комментарий
Так как в задаче отсутствуют уточнения/требования по вводным данным, предположим, что ввод будет массивом целых чисел.
Для нахождения решения необходимо найти подмножество элементов изначального массива - некоторый отрезок, концы которого определяются индексами масимального и минимального элементами массива.
Найти максимальный и минимальный элементы массива возможно засчет итерации по списку и последовательного сравнения элементов между собой.
В качестве максимального и минимального элемента первоначально возьмем первый элемент массива под нулевым индексом.
Для этого объявим две переменные типа int - min_val и max_val, а также еще две переменные для хранения индексов этих элементов - min_val_idx и max_val_idx соответственно.
Выполним итерацию по списку в цикле for, начиная с нулевого индекса до значения длины массива минус один, чтобы перебрать все элементы массива, 
и последовательно сравним все элементы с первоначальными значениями min_val и max_val. Если элемент массива под индексом i меньше текущего значения min_val, мы присвоим значение этого элемента переменной min_val, а значение i - переменной min_val_idx, сделаем тоже самое для значения max_val с условием "больше".
Проитерировавшись по всем элементам массива, мы имеем максимальный и минимальный (по значению) элементы массива, а также их индексы.
Объявим новую переменную для подсчета суммы отрицательных элементов - result и присвоим ей проинициализируем ее первоначальным значением 0.
Для выяснения начала и конца отрезка в массиве сравним имеющиеся значения индексов минимального и максимального элементов.
Меньшее значение индекса будет началом отрезка в массиве, а большее - концом. Объявим новые переменные start_idx и end_idx.
Имея начало и конец отрезка, выполним еще один цикл для нахождения суммы: начиная с start_idx и заканчивая end_idx, не включая концы (согласно условию). 
В новой итерации мы сравним каждый следующий элемент отрезка с нулем: если эелемент меньше нуля, мы можем сложить его с текущим значением переменной result и присвоить результат этой же переменной.
В результате второго цикла мы получим суму всех отрицательных элементов между максимальным и минимальным элементами массива.

Задача решена в два прохода: один по полному списку и второй по отрезку между двумя ключевыми элементами.
Временная сложность вычисления - линейная.
Худшая временная сложность (O): 2n, т.е. два полных прохода по массиву в случе если ключевые элементы оказались на противоположных концах исходного массива.
Лучшая/средняя временная сложность (Ω): n, в остальных случаях.
