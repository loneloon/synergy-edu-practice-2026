#### Комментарий
Для наглядной демонстрации наследования классов в C++ выберем простую доменную модель с набором потенциально транзитивных базовых параметров - контейнер (физический контейнер, в контексте логистики). 
В качестве потенциальных наследников выберем типы объемных контейнеров разных форм - коробка(Box), 
сфера(Sphere), цилиндр(Cylinder).
Для общих публичных аттрибутов базового класса Container выберем те, которые будут справедливы для каждого класса наследника - объем(volume) и площадь поверхности(surfaceArea), а также метод для вывода значений (printInfo).
Реализуем класс Container как абстрактный и опишем для него публичный интерфейс, который будут наследовать другие классы. Конструктор класса объявим как виртуальный; также аттрибуты класса - объем и площадь поверхности с типом double объявим виртуальными с подходящим типом double для увеличенной точности, уместным в подобных расчетах, с дефолтными значениями равными нулю.
В качестве первого конкретного класса, наследующего базовый класс Container с спецификатором доступа public (для сохранения публичных аттрибутов класса таковыми), реализуем BoxContainer.
Для дальнейшего расчета объема и площади поверхности введем новые аттрибуты - ширину, высоту и глубину контейнера.
Для инициализации аттрибутов класса укажем в конструкторе соответствующие параметры, которые при инициализации передадим/будем хранить в приватных аттрибутах класса width_, height_, depth_: мы ограничиваем к ним доступ извне, так как изменение исходных параметров объекта после инициализации не подразумевается.
Далее мы опишем конкретную реализацию виртуальных методов базового класса volume и surfaceArea в соответствии с геометрией контейнера. Объем коробки будет рассчитываться как произведение ширины, высоты и глубины, а площадь поверхности будет удвоенной суммой попарно перемноженных между собой размерностей контейнера.
Помимо переопределения методов расчета объема и ПП, мы также можем расширить метод для вывода данных о контейнере в консоль, добавив вывод новых аттрибутов к уже реализованному выводу объема и ПП в базовом классе, обратясь к методу printInfo через базовый класс.
Аналогичным образом реализуем два других конкретных класса, наследующие базовый класс Container - сферический и цилиндрический контейнеры.
SphereContainer в качестве классо-специфичного аттрибута будет иметь радиус и соответствующий входной параметр в своем конструкторе, а CylinderContainer будет иметь радиус и высоту.
Далее реализуем расчет объема и ПП для сферы и цилиндра пользуясь их геометрическими формулами и дополним их реализации метода вывода.
Для демонстрации использования классов наследников инициализируем по одному экземпляру для каждого конкретного класса со случайными аргументами. Соберем инициализированные инстансы по указателям в массиве с их общим базовым типом Container*[] и выведем справку о каждом из них в цикле.
